# 00 — Baseline and attribution

The baseline first closed the retained functional suite, then defined explicit
ROI start/end and retirement semantics. Exclusive counters were calibrated
before any optimization hypothesis was accepted. Baseline ROI cycles were
11,978 for FIB, 1,860 for Bubble, 590,363 for GOL128, and 2,394,963 for GOL256.
This stage established the metric contract used by every later comparison.
